# Analise-de-dados
Este repositório reúne projetos de análise de dados desenvolvidos com o objetivo de construir e demonstrar meu portfólio na área.
Aqui você encontrará estudos práticos envolvendo limpeza, exploração, visualização e modelagem de dados, utilizando diferentes ferramentas e técnicas.

Os projetos abordam problemas reais ou simulados, com foco em extrair insights relevantes, comunicar resultados de forma clara e aplicar boas práticas de ciência de dados. Este espaço será continuamente atualizado com novas análises, refletindo minha evolução e aprendizado na área.

Tecnologias e habilidades exploradas incluem Python, pandas, visualização de dados, estatística e aprendizado de máquina.
